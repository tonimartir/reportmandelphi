Descarga

Obtenga la última versión de Report Manager y sus paquetes.

Report Manager está alojado en SourceForge. Descargue la última versión desde la página del proyecto en SourceForge.

La versión incluye los siguientes paquetes:

  • Diseñador de informes Report Manager (Windows y Linux)
  • Paquetes de componentes para Delphi, C++Builder y FPC/Lazarus
  • Componente ActiveX de Report Manager
  • Biblioteca .NET y .NET Core

Los paquetes del diseñador también incluyen el control ActiveX (Windows) y el servidor web de informes (Windows y Linux).

Para desarrollo en .NET hay paquetes disponibles en NuGet y en un repositorio de GitHub dedicado.

Diseñador para el escritorio Linux

La carpeta Linux de cada versión en SourceForge contiene el diseñador Report Manager Designer para el escritorio Linux (64 bits):

  • reportman-designer_<versión>_amd64.deb — Qt 6, recomendado, para Ubuntu 22.04 o posterior y Debian 12 o posterior
  • ReportManDesigner-<versión>-x86_64.AppImage — Qt 6, para otras distribuciones, sin instalar nada
  • reportman-designer-gtk2_<versión>_amd64.deb — GTK2, de transición

Consulte la guía de instalación en Linux (en inglés).

Lazarus y Free Pascal

Instale los paquetes de Report Manager (motor con exportación a PDF, vista previa LCL y diseñador integrable) desde el Online Package Manager de Lazarus (Paquete → Online Package Manager), o compílelos desde el código fuente. Consulte Lazarus / Free Pascal (en inglés).

macOS

La carpeta macOS de la versión en SourceForge contiene el diseñador Report Manager Designer para macOS, con la interfaz nativa Cocoa:

  • reportman-designer-<versión>-macos-x86_64.dmg — Mac con procesador Intel, probado en macOS 11; ábralo y arrastre la aplicación a Aplicaciones. Incluye los ejemplos (entre ellos sample4).

La aplicación no está notarizada por Apple: la primera vez, ábrala desde el Finder con clic derecho → Abrir. HTTPS (los asistentes de IA y el driver Reportman DB Agent) necesita OpenSSL 3 (brew install openssl@3). Los paquetes de Lazarus y el diseñador también se compilan desde el código fuente: consulte macOS (Lazarus, Cocoa) (en inglés).

Servidor web de informes en Docker

El servidor web de informes también se publica como imagen Docker, tonimartir/reportman-web. Consulte Servidor web.
