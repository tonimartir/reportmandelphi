Download

Get the latest Report Manager release and packages.

Report Manager is hosted on SourceForge. Download the latest release from the SourceForge project page.

The release includes the following packages:

  • Report Manager Designer application (Windows and Linux)
  • Component packages for Delphi, C++Builder and FPC/Lazarus
  • Report Manager ActiveX component
  • .NET and .NET Core library

The designer packages also include the ActiveX control (Windows) and the Web Report Server (Windows and Linux).

For .NET development, packages are available on NuGet and in a dedicated GitHub repository.

Linux desktop designer

The Linux folder of each release on SourceForge contains the Report Manager Designer for the Linux desktop (64-bit):

  • reportman-designer_<version>_amd64.deb — Qt 6, recommended, for Ubuntu 22.04 or later and Debian 12 or later
  • ReportManDesigner-<version>-x86_64.AppImage — Qt 6, for other distributions, nothing to install
  • reportman-designer-gtk2_<version>_amd64.deb — GTK2, transitional

See the Linux installation guide.

Lazarus and Free Pascal

Install the Report Manager packages (engine with PDF export, LCL preview and embeddable designer) from the Lazarus Online Package Manager (Package → Online Package Manager), or build them from the source code. See Lazarus / Free Pascal.

macOS

The macOS folder of the release on SourceForge contains the Report Manager Designer for macOS, with the native Cocoa interface:

  • reportman-designer-<version>-macos-universal.dmg — a universal application for Intel Macs (macOS 10.15 or later) and Apple Silicon Macs (M1 and later, macOS 11 or later), tested on macOS 11 (Intel) and macOS 15 (Intel and Apple Silicon); open it and drag the application to Applications. It includes the samples (sample4 among them), and the .rep files open with it from the Finder.

The application is not notarized by Apple: the first time, open it from the Finder with right click → Open. It includes OpenSSL 3 for HTTPS (the login, the AI assistants and the Reportman DB Agent driver). The Lazarus packages and the designer also build from the source code: see macOS (Lazarus, Cocoa).

Web Report Server in Docker

The Web Report Server is also published as a Docker image, tonimartir/reportman-web. See Web Server.

Web Designer in Docker

Reportman Server, the web designer with the AI copilot, the report store and a public API to run reports, is published as tonimartir/reportman-server. See Web Designer.
