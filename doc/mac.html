Report Designer for macOS

A native Cocoa application for Intel and Apple Silicon Macs. Free and open source.

Download the .dmg

The Report Manager Designer runs on the Mac as a Mac application: a native Cocoa interface, a universal binary for Intel and Apple Silicon, and a .dmg you drag to Applications. No Java runtime, no Electron, no Windows virtual machine.

It is the same designer as on Windows and Linux, and the reports are the same .rep files: design one on your Mac and run it from the Delphi, Lazarus or .NET engine, from the report servers or from the web designer.

What you can do with it

  • Design reports visually: bands, groups, subreports, expressions, charts and barcodes.
  • Connect to your database. Both engine drivers work on macOS — FireDAC connections opened with SQLdb and Zeos connections — for PostgreSQL, MySQL or MariaDB, Firebird, SQLite and ODBC. See databases on macOS for the client libraries each one needs.
  • Reach a remote database through the Reportman DB Agent, outbound-only, without a VPN.
  • Export to PDF, SVG, HTML, text and CSV, and print from the macOS print dialog.
  • Use the AI assistants: the report design chat, the SQL and expression chats, and inline suggestions in the SQL editor, which also completes from your schema.
  • Open a .rep file straight from the Finder. The samples are installed with the application.

Requirements

  • Intel Macs: macOS 10.15 or later.
  • Apple Silicon Macs (M1 and later): macOS 11 or later.
  • A single universal application for both; tested on macOS 11 (Intel) and macOS 15 (Intel and Apple Silicon).

Install it

Download reportman-designer-<version>-macos-universal.dmg from the macOS folder of the release on SourceForge, open it and drag the application to Applications.

The application is signed ad hoc and not notarized by Apple, so the first time you have to open it from the Finder with right click → Open. After that it opens like any other application. It carries its own OpenSSL 3 for HTTPS, which is what the login, the AI assistants and the Reportman DB Agent driver use.

The small print

We would rather say it here than have you find out:

  • Printing works, and on macOS it needed fixing: Lazarus itself printed blank sheets, because its Cocoa printer leaves the page margins undefined, so the designer sets them. It is tested through the macOS printing system, with a printer that writes each job to PDF: portrait and landscape, several reports, one of them two pages with images.
  • With LCL on Cocoa, text in the preview and on paper is not drawn exactly as the engine draws it: uneven letter spacing and a different font. The PDF, SVG and HTML you export are not affected.
  • The Monaco SQL editor is Windows only. On macOS the SQL editor is the native one, with schema completion and AI inline suggestions, as on Linux.
  • On Apple Silicon, so far only the automated tests have been run on every release.

For Lazarus and Free Pascal developers

The engine, the LCL preview and the embeddable designer are also Lazarus packages, and everything — packages, examples and designer — builds from the source code on macOS with Cocoa: see Report Manager on macOS (Lazarus, Cocoa) for the toolchain, the fonts, OpenSSL 3 and the database client libraries.

The source code is on GitHub and on SourceForge, under the MPL license. The other packages of the release are on the download page.
